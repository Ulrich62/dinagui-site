# Tutoriel : Création d'une signature professionnelle Outlook pour Dinagui

Bonjour,

Voici la procédure complète pour configurer une signature Outlook professionnelle et identique pour tous les collaborateurs, en se basant sur l'exemple de la capture fournie.

---

## Étape 1 : Ouvrir les paramètres de signature

Dans Outlook (application Windows) :
1. Cliquez sur **⚙️ Paramètres** (en haut à droite).
2. Allez dans **Comptes**.
3. Cliquez sur **Signatures**.

> 💡 *(Si vous utilisez Outlook classique : allez dans **Fichier** → **Options** → **Courrier** → **Signatures**.)*

---

## Étape 2 : Créer une nouvelle signature

Cliquez sur le bouton **Nouvelle signature**.

Donnez-lui un nom clair. Par exemple : **Signature Dinagui**.

---

## Étape 3 : Copier les informations

Copiez-collez les informations suivantes dans la zone d'édition (voici l'exemple de référence) :

**DINAGUI SARL**  
*Service Client*  

📞 +224 613 50 04 04  
📧 contact@dinagui.com  
📍 Siège social : Kipé, Centre Émetteur  
Conakry – République de Guinée  
🌐 https://dinagui.com  

---

## Étape 4 : Ajouter le logo

1. Placez votre curseur en dessous du texte.
2. Cliquez sur l'icône **Insérer une image**.
3. Sélectionnez le logo de **Dinagui** sur votre ordinateur.
4. Le logo apparaîtra directement dans votre signature.

---

## Étape 5 : Définir la signature par défaut

Dans la section définissant les signatures par défaut, choisissez :
* **Nouveaux messages** → *Signature Dinagui*
* **Réponses et transferts** → *Signature Dinagui*

Puis cliquez sur **Enregistrer** pour valider.

---

## 📌 Standardisation pour tous les employés

Pour conserver une image de marque professionnelle et cohérente, il est essentiel de garder **exactement la même mise en page** pour chaque employé. 

Chaque personne devra uniquement modifier ses informations personnelles :
* Son Nom et Prénom
* Sa Fonction
* Son numéro de Téléphone
* Son adresse e-mail

**Tout le reste (le logo, l'adresse physique, le site web et les couleurs) reste strictement identique.**
